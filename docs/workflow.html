Answer questions about a document without handing it over

ContextGuard sits between your files and the AI that answers about them. Claude works out what is private; ordinary code does the removing. The agent that answers you never receives the original.

Claude decides Code enforces Never crosses

What happens, step by step

  1. 1 You upload files and ask a question. PDFs or images — an invoice, a claim form, an HR record. Several at once is fine.
  2. 2 Claude reads the originals and decides what's private. Not just "is this a name" but "does this question actually need it?" Two different questions about the same invoice produce two different answers. CLAUDE DECIDES
  3. 3 Code does the removing — not Claude. Images get blacked out. In PDFs the text is deleted outright, not covered over, so it can't be copied out later. Then it checks its own work. CODE ENFORCES
  4. 4 A cleaned copy is written to a separate place. The originals stay behind. Anything that couldn't be fully cleaned is held back entirely. CODE ENFORCES
  5. 5 A second Claude answers using only that copy. It has no access to the originals, so it cannot reveal what was removed — even if asked directly. CLAUDE ANSWERS

Why it's built this way

Why two Claudes instead of one?

The one that reads your private documents doesn't answer you. The one that answers never sees them. Nothing can slip out by accident, because the part talking to you never had it.

The same detail isn't always private

Ask "which item costs the most?" and the bank account is hidden. Ask "which account do I pay?" and it's kept. What counts as private depends on what you asked.

Claude judges, code enforces

Deciding what's sensitive needs judgement, so Claude does it. Deciding what's allowed to leave is a rule, so plain code does it — the same way every time, with no room for persuasion.

When unsure, nothing goes out

If the system can't confirm it removed everything it meant to, it holds the whole document back and says so. Releasing nothing beats releasing something half-cleaned.
